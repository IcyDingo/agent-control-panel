Get the panel

Agent Panel is a page on your Mac that shows every Claude Code session and lets you answer them from one place. It also counts your agents' work and grows your galaxy here.

You need a Mac on macOS 14 or newer, Claude Code 2.1.303 or newer, Node 20 or newer, and Apple's Command Line Tools. The installer says what is missing.

git clone https://github.com/IcyDingo/agent-control-panel.git
cd agent-control-panel
./install.sh
  1. It builds Agent Panel.app into your Applications folder and installs a background service, so your work is counted whether or not the app is open. Keep the folder you cloned: the app runs from it.
  2. Open Agent Panel. macOS may ask whether it may use your Documents folder; the panel reads the repositories your sessions work in. Press Connect this profile once, and sessions you start from then on show up.
  3. Sign in from the Profile box in World, or with node server.mjs login. Approve the code here with GitHub, and your galaxy gets its permanent spot in the Universe.
  4. Update with git pull and ./install.sh again. It rebuilds the app and restarts the service on the new code.

The full manual, with what is shared and what never leaves your Mac, is the README. The hub itself can be run on your own.
